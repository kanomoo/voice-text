### 1.2 การไล่โค้ดการลบข้อมูลค่าน้อยสุด (`deleteMin`)
> "เมธอด `deleteMin(self)` มีความสำคัญและซับซ้อนกว่า:  
> 1. ค่าที่น้อยที่สุดจะอยู่ที่รากเสมอ คือ `min_item = self.array[1]`  
> 2. เราจะนำค่าจากโหนดตัวสุดท้ายของฮีป (`last_element = self.array[self.current_size]`) มาเตรียมใส่ แต่เราไม่ใส่ลงรากทันที เพราะมันจะผิดกฎ Heap-Order Property!  
> 3. เราลดขนาด `self.current_size -= 1`  
> 4. ทำการ **Percolate Down (การจมตัวลงสู่ก้นบึ้ง):**  
>    - ดูที่ช่องว่างตำแหน่งที่ 1 (ราก)  
>    - ตรวจสอบโหนดลูกซ้าย (`Child = 2 * hole`) และโหนดลูกขวา (`Child + 1`)  
>    - **เลือกลูกตัวที่ค่าน้อยกว่าขึ้นมาเปรียบเทียบ:**  
>      `if Child != self.current_size and self.array[Child + 1] < self.array[Child]: Child += 1`  
>    - ถ้า `last_element` มีค่ามากกว่าลูกตัวที่น้อยกว่า ให้เลื่อนลูกตัวนั้นขึ้นมาแทนที่ช่องว่าง แล้วเลื่อนช่องว่างลงไปที่ตำแหน่งของลูกนั้น  
>    - ทำซ้ำจนกว่า `last_element` จะมีค่าน้อยกว่าลูกทั้งสอง หรือช่องว่างลงไปถึงชั้นล่างสุด แล้วจึงวาง `last_element` ลงในช่องว่างนั้น..."

## 2. สรุปขั้นตอน Algorithm และโครงสร้างโค้ด Python

### โค้ดต้นแบบ `BinaryHeap` (ตามที่อาจารย์สอนในคาบ)

```python
class BinaryHeap:
    def __init__(self, capacity=100):
        self.current_size = 0
        self.array = [0] * (capacity + 1)

    def insert(self, x):
        # 1. ขยายขนาดและเตรียมช่องว่างที่ตำแหน่งปลายสุด
        self.current_size += 1
        hole = self.current_size
        
        # 2. ทำ Percolate Up: เลื่อนพ่อแม่ลงมาถ้าพ่อแม่มากกว่า x
        self.array[0] = x  # Sentinel ป้องกัน index out of bounds
        while x < self.array[hole // 2]:
            self.array[hole] = self.array[hole // 2]
            hole = hole // 2
            
        # 3. บรรจุค่า x ลงในช่องว่างที่เหมาะสม
        self.array[hole] = x

    def deleteMin(self):
        if self.current_size == 0:
            return None
            
        min_item = self.array[1]
        last_element = self.array[self.current_size]
        self.current_size -= 1
        
        hole = 1
        while hole * 2 <= self.current_size:
            child = hole * 2
            # เลือกลูกตัวที่ค่าน้อยกว่าระหว่างลูกซ้ายกับลูกขวา
            if child != self.current_size and self.array[child + 1] < self.array[child]:
                child += 1
                
            # ถ้า last_element มากกว่าลูกตัวที่น้อยกว่า ให้ดึงลูกขึ้นมา
            if self.array[child] < last_element:
                self.array[hole] = self.array[child]
                hole = child
            else:
                break
                
        self.array[hole] = last_element
        return min_item
```
